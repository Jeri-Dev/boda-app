# boda-app — conventions

PWA to manage a single wedding. **The app is open — there is NO authentication.** Two surfaces, one database:

- **Back-office** (`(host)` route group) — wedding management (guests, budget, vendors, tasks, tables, floor plan). Lives at the app root `/`. `robots: noindex`. Access control, if any, is at the deployment layer (private URL, password-protected hosting, local use) — never in the app.
- **Guest-facing** (`(public)` route group) — `/i/[token]` invitation + RSVP, `/info` web + gift registry, `/~offline` fallback.

Stack: Next.js 16 (App Router, React 19) · **Drizzle ORM + libSQL** (SQLite local in dev, Turso/libSQL remote in prod by env) · Tailwind v4 (CSS-first, no `tailwind.config.ts`) · Zod 4 · Playwright · pnpm.

## Data layer (Drizzle + libSQL)

- **One client:** `src/lib/db/index.ts` (`import 'server-only'`) exports `db`. The SAME code serves dev and prod — only `DATABASE_URL` changes (`file:local.db` → `libsql://…turso.io` + `DATABASE_AUTH_TOKEN`).
- **Schema** in `src/lib/db/schema.ts`. Pattern for constrained columns: `text({ enum: [...] })` + a SQL `check()` (type-safe in TS *and* enforced in SQLite). Timestamps as unixepoch integers; `$onUpdate` refreshes `updated_at`.
- **Migrations** in `src/lib/db/migrations/` are generated by `pnpm db:generate` and committed (including `meta/_journal.json`). Apply with `pnpm db:migrate`. NEVER run migrations inside the serverless runtime — do it as a separate deploy/CI step against Turso.
- `@libsql/client` uses native bindings → **Node.js runtime only, never Edge**. Listed in `serverExternalPackages` in `next.config.ts`.

## Next.js 16 reminders

- `cookies()` / `params` are async (await them). `redirect()` throws — call it **outside** try/catch.
- Read `node_modules/next/dist/docs/01-app/` before touching routing. Avoid `'use cache'`.
- Server Action recipe (no auth gate): `'use server'` → `Schema.safeParse` → mutate via `db` → `revalidatePath` → `redirect()` outside try/catch.

## Local dev

- `pnpm dev` — app. `pnpm db:generate` — generate a migration from `schema.ts`. `pnpm db:migrate` — apply to the local DB. `pnpm db:studio` — Drizzle Studio.
